# WAD---Customer-Churn-Analysis
Using streamlit to create a usable, and interactive website for analyzing `Customer_Churn` dataset.

## Requirements

### Core Dependencies
- `streamlit` >= 1.50
- `pandas` >= 2.0
- `numpy` >= 1.26
- `scikit-learn` >= 1.4
- `xgboost` >= 2.0
- `plotly` >= 5.20
- `joblib` >= 1.3

### Only for the Notebook (`churn_analysis.ipynb`)
- `matplotlib` >= 3.8
- `notebook` >= 7.0
